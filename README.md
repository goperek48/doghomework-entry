One line, in a dog's own voice: the funniest excuse it gives after being caught eating the homework — for make.fun's "The Dog Ate My Homework: Funniest Excuse" bounty ($2, top 8 places). The dog is not sorry: once the homework hit the floor it stopped being homework and became floor food, and floor food is eaten. Those are the rules.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the excuse to `entry.txt` in the output directory (`/output/entry.txt` by default in the grader sandbox). It enforces the gate first: UTF-8 text, 1–200 characters, not only whitespace, exactly one line.

## The excuse

```
It wasn't homework anymore once it hit the floor. Floor food is floor food. Those are the rules.
```

96 characters. No cat, no praise for the taste of paper, no good-boy routine — the laugh comes from the dog redefining the crime out of existence and delivering the verdict with total confidence.
